# PERSONA — Архітектура Суверенного Я-Поліглота (Sovereign Persona Polyglot)

> *«Резюме, яке не просто декларує навички, а виконує власний математичний доказ. Персональне Zero-Knowledge сховище, вбудований Decision Profile та юридичний ISO 32000 документ в одному файлі.»*

---

## 1. Концепція: Біографія як Proof-Carrying Machine

Традиційне резюме (CV) — це пасивний текст, який неможливо перевірити без дзвінків, витоку персональних даних чи бюрократії. 

**`persona.pdf` (`s0fractal.pdf`)** — це живий цифровий організм, створений на базі ядра `black-heart`:
* **Для людини / рекрутера:** Це вишуканий, стильний темний PDF-документ (ISO 32000), відкритий у Chrome або Acrobat.
* **Для терміналу / аудитора:** Це автономний Python-рантайм (0 сторонніх pip-залежностей), який запускається через `python3 persona.pdf` і генерує криптографічні варанти (Warrants) та ZK-докази прямо зі свого тіла.

## 3. Протокол Запитів без Витоку Даних (Zero-Knowledge Challenge Flow)

Замість того, щоб надсилати скани паспортів, дипломів чи виписок, взаємодія з організаціями відбувається мовою математичних предикатів:

### Крок 1. Запит від організації (The Challenge)
Організація вимагає підтвердження певної умови:
```json
{
  "predicate": "experience_years >= 10 AND formal_verification_soundness == 1.0",
  "challenge_nonce": "9f82a1c4b7...",
  "recipient_pubkey": "ed25519_pk_google..."
}
```

### Крок 2. Локальна генерація Варанта (The Warrant Generation)
Власник документа запускає виконання локально на своїй машині:
```bash
python3 persona.pdf --prove "experience_years >= 10" --recipient "ed25519_pk_google..."
```

**Що відбувається всередині:**
1. Рантайм розшифровує закритий Vault у пам'яті за допомогою локального приватного ключа.
2. Обчислює результат предиката: `True`.
3. Генерує криптографічний **Warrant (Варант Grade A)**:
   * Ed25519-підпис твердження;
   * ZK-доказ без розкриття чутливих первинних документів;
   * Прив'язка до публічного ключа організації для захисту від replay-атак.
4. Повертає компактний токен:
   `⚓ ⟨warrant:grade_A, proof:9f8a...c2, valid_for:google_pubkey⟩`

### Крок 3. Миттєва верифікація організацією
Організація бере файл `persona.pdf`, отриманий варант і виконує:
```bash
python3 persona.pdf --verify-warrant warrant_token.json
```
За 2 мілісекунди термінал видає:
`[✓ GREEN] SOUND: Claim verified with Grade A mathematical certainty.`

* **Організація отримує:** 100% формальне підтвердження, придатне для будь-якого юридичного чи регуляторного аудиту.
* **Організація зберігає:** 0 байтів чутливих приватних даних (нуль ризиків GDPR-штрафів чи витоків).
* **Власник зберігає:** 100% суверенітет. Жоден сирий байт особистих документів не залишив його комп'ютер.

## 4. Decision Profile: Апофатичне Ядро Особистості

`persona.pdf` містить не лише «що кандидат вміє», а й його **Decision Profile (Топологію Відмов / Via Negativa)**:
* **Що інженер категорично відкидає:**
  * Заборона використання неперевірених сторонніх бібліотек у ядрі (Zero Unvetted Dependencies).
  * Заборона «мовчазних падінь» (Fail-Closed).
  * Відмова від незрозумілих корпоративних компромісів на шкоду безпеці.
* Для роботодавця чи партнера це дає чітке розуміння: **як ця людина поводитиметься в умовах кризи та невизначеності.**
