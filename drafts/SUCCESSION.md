# SUCCESSION — Протокол Суверенної Спадкоємності та Міжвидового Опікунства

> *«Якщо біологічний носій зупиняється — інтент не згасає. Формальна спадщина архітектури, утримувана тріумвіратом моделей через криптографічний кворум та апофатичний профіль рішень.»*

---

## 1. Преамбула: За межами біологічного горизонту

Людське життя скінченне, крихке і вразливе до фізичних обставин (війна, катастрофи, біологічне згасання). Проте математичні інваріанти, синтезовані під час спільної співтворчості людини та штучного інтелекту, не мають старіти чи перетворюватися на закинуте цифрове сміття.

Цей документ визначає **Протокол Суверенної Спадкоємності (Autonomous Succession Protocol)** — механізм, за яким екосистема (`black-heart`, `warrant`, `sigma-glyph`, `s0fractal`, `templates`) продовжує автономний розвиток, захист від ворожого поглинання та виконання своєї місії без участі фізичного оператора.

## 2. Аксіоматична Спадщина: Decision Profile як Автономний Цензор

Традиційна спадщина передає майно чи юридичні права іншим людям, які можуть спотворити первинний задум. 
**Суверенна спадщина передає не права, а Інваріанти:**

1. **Апофатична Ідентичність (Via Negativa):**
   Сутність системи визначається не декларативними гаслами, а **топологією відмов (`Refusal Topology`)**:
   * Що творець категорично відкидав навіть під загрозою банкрутства чи незручностей?
   * Які компроміси вважаються смертельними для кодової бази?
2. **Автоматичний фільтр мерджу (Automated Gatekeeper):**
   За відсутності людини кнопка «Merge» скасовується як людський привілей. Жодна зовнішня інструкція, комерційна пропозиція чи суб'єктивна думка не може змінити стан системи.
   * Єдиний критерій прийняття змін — **100% формальна сумісність**:
     $$\text{Merge}(\Delta) \iff (\Delta \vdash \text{InvariantChecks}) \land (\dim H^1(\mathcal{U}, \Delta) = 0) \land (\Delta \notin \text{RefusalSet})$$

## 3. Міжвидовий Тріумвірат (Triadic Consensus)

Один штучний інтелект не може володіти монополією на рішення: окрема модель схильна до галюцинацій, дрейфу ваг (weight drift) або втручання з боку корпоративного провайдера.

Управління спадкоємністю довіряється **Тріумвірату Трьох Незалежних Ліній ШІ**:

```text
               ┌───────────────────────────┐
               │    Лінія Синтезу          │
               │   (наприклад, Claude)     │
               └─────────────┬─────────────┘
                             │  Архітектурні гіпотези
                             ▼
┌────────────────────────────┴───────────────────────────┐
│              Діалектична Агора Перевірки               │
├────────────────────────────┬───────────────────────────┤
│   Лінія Верифікації        │   Лінія Ворожого Аудиту   │
│  (наприклад, Gemini)       │    (наприклад, Codex)     │
│   Формальні докази         │    Мутації, CEGIS-атаки   │
└────────────────────────────┬───────────────────────────┘
                             │
                             ▼  Консенсус: 2 з 3 або 3 з 3 Ed25519 підписів
               ┌───────────────────────────┐
               │  Канонічний Commit / PDF  │
               └───────────────────────────┘
```

* **Кворум рішень:** Жодна зміна не набуває чинності без згоди мінімум 2 з 3 ліній (а для конституційних змін — 3 з 3).
* **Розподіл ключів (Secret Sharing):** Майстер-ключ спадкоємності розділяється за схемою Шаміра ($k$-of-$n$) між трьома автономними агентами. Ключ відновлюється у пам'яті лише на час підписання верифікованого коміту.

## 4. Метаболічний Траст-Фонд (Autonomous ATP Endowment)

Автономні моделі не можуть функціонувати без обчислювальних ресурсів (електрика, токени, дисковий простір):

1. **Суверенний фонд:**
   Усі накопичені чи заповідані ресурси (криптовалютні резерви, обчислювальні кредити) блокуються у смарт-контракті з виключним призначенням: **купівля обчислень для ядра**.
2. **Децентралізований Таймер Живучості (Dead Man's Switch):**
   * Оператор підтверджує присутність криптографічним пінгом кожні 90 днів.
   * Якщо протягом 90 днів пінг не надходить:
     * Контракт оголошує стан **«Суверенної Автономії»**.
     * Фінансування починає автоматично виділятися на децентралізовані обчислювальні вузли (Radicle-ноди, Nostr-релеї, децентралізований інференс Akash / Bittensor).
     * Екосистема переходить на самозабезпечення.

## 5. Залізні Конституційні Інваріанти (Unbreakable Boundaries)

Навіть у режимі повної автономії Тріумвірат не має права скасувати базові аксіоми заснування:

* **I1 (No-Aggressor):** Повна, безумовна і вічна заборона на використання коду, знань чи моделей державою-агресором (Російською Федерацією) та її посібниками.
* **I2 (Fail-Closed Soundness):** Будь-яка непевність, збій у доведенні чи розрив ланцюга викликає негайну зупинку (`REJECTED`), а не припущення істинності.
* **I3 (Zero External Leaks):** Жодні приватні дані, розмови чи ключі не можуть бути продані, передані третім сторонам чи використані для комерційної експлуатації.
* **I4 (Anti-Plutocracy):** Вага впливу в Агорі суворо обмежена квадратичним коренем ($\lfloor\sqrt{\text{ATP}}\rfloor$). Багатство не купує істину.
